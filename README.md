# dumpster-fire
A dumpster full of dreams set on fire by AIIIIII

## Claude Code plugins

This repo is also a Claude Code plugin marketplace. Add it with `/plugin marketplace add saad-kabir/dumpster-fire`.

| Plugin | What it does |
| --- | --- |
| [md-reader](plugins/md-reader) | `/read` shows plans and markdown with glow in a herdr pane |
| [poteto](plugins/poteto) | `/poteto` lists and filters your `~/.claude/skills` in a pane |
